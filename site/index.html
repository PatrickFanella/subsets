A FEW DELIBERATE STEPS

A set for the
work at hand.

Your library stays available.
You choose what’s active.

  1. 01

    Find what’s there.

    Scan supported user and project skill folders. Review where each skill lives and who owns it.

    subsets discover
  2. 02

    Make a working set.

    Adopt an unmanaged folder, then group its skills for a task. Add everyday essentials to core.

    subsets group create creative-writing editing research
  3. 03

    Look before you apply.

    Preview what will change. Apply the selection when it’s right, then start a fresh agent session.

    subsets apply --creative-writing --dry-run
  4. 04

    Keep a way back.

    Inactive skills stay in your private library. Review transaction history and roll back a change when the saved state still matches.

    subsets history

You decide which folders it manages.

Discovery is read-only. Adoption is explicit. Package and plugin folders keep their owners, and later edits stop apply or rollback rather than being overwritten.
