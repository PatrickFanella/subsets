# Subsets identity

Subsets uses Personal Utility: silver gray, charcoal, mint selected states, a lowercase wordmark, and an original six-tile mark. The owner selected the direction and approved the refinement on October 4, 2026.

The brand masters belong to SUBCULT Studio in the private `subcult-tv` repository, under `studio/branding/library/brands/subsets/`. This repository receives explicitly selected exports. `assets/brand/brand-export.json` and `site/assets/brand/brand-export.json` record their source hashes. Edit the Studio configuration and generator, then export; do not maintain a second editable identity here.

The native TUI uses mint for the title, selected group names, borders, and cursor. It preserves the terminal's background and ordinary text colors, so the user's terminal theme still controls those surfaces. CLI JSON output remains machine-readable. Plain help identifies the product and links to its landing page and support.

The landing uses Space Grotesk headings, Public Sans explanations, and JetBrains Mono commands. Included fonts retain their OFL licenses. Outlined lockups need no installed fonts. Use the monochrome mark at 16–24 pixels and the full-color mark at 32 pixels or larger. Keep one tile of clear space around the mark geometry. Use charcoal on mint for text; mint on silver does not have sufficient small-text contrast.
